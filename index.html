Что умеет программа

Основные функции собраны коротко, чтобы новый человек быстро понял, зачем нужен Гусь и как он работает с открытыми MAX.

Работа с MAX

Находит открытые окна MAX, показывает выбранные профили и распределяет обработку между ними.

Клиенты из TXT

Берёт базу из текстового файла, ведёт очередь и отмечает результат обработки строк.

Группы и ЛС

Может работать через группы или писать в личные сообщения на выбранных MAX.

Несколько профилей

Показывает, сколько клиентов обработал каждый профиль, и помогает работать параллельно.

Автообновление

Рабочие ПК читают этот канал обновлений и скачивают новый zip-пакет по кнопке в программе.

Доступы

Вход по аккаунтам помогает не давать пользоваться программой без разрешения владельца.

Доступ к программе

Обычным пользователям достаточно скачать установщик. Аккаунты и оплату владелец ведёт отдельно через админ-панель.

Для рабочего ПК

Скачай установщик, выбери папку, затем запускай Гусь с рабочего стола.

Для владельца

Админ-панель открывается отдельно и не мешает обычному сайту установки.

Для отката

Архив версий ниже хранит старые сборки, чтобы можно было быстро вернуться назад.

Архив версий
